# NEXUS Academy Full Curriculum Roadmap (120 Missions)

**Target Outcome**: Professional Junior ML/AI Developer (Capable of AI Startup Operations)
**Design Philosophy**: 5-Phase Architecture. Pedagogy evolves as capability increases. The 'WHY' remains constant.

---

## Phase 1: Foundation (Missions 001–025)
**Goal**: Build the engineering mindset from zero. Focus on basic Python constructs and control flow.
**Pedagogy**: Full 13-step format (Deep Story, Analogy, 3x Practice, 3x Debug, Critical Thinking Lab).

- **001**: "Print & Execution" — How a program runs top-to-bottom.
- **002**: "Variables (String)" — Memory and data labeling.
- **003**: "Variables (Update)" — Mutating memory states.
- **004**: "Variables (Integer)" — Numerical data.
- **005**: "Type Conversion" — Transforming data boundaries (int vs str).
- **006**: "Integer Assignment Pipeline" — The `=` flow and basic math (+, -, *).
- **007**: "Float Division" — Decimals and precision limits (`/`).
- **008**: "User Input" — The listening software (`input()` with strings).
- **009**: "Dynamic Math" — Combining `input()` and `int()` to process live numbers.
- **010**: "String Formatting" — `f-strings` for building complex dynamic outputs.
- **011**: "Boolean Logic" — True, False, and logical truth.
- **012**: "Comparison Operators" — `==`, `<`, `>`, evaluating states.
- **013**: "The Decision Tree" — `if` statements and branching paths.
- **014**: "Alternative Paths" — `else` and handling failure states.
- **015**: "Multiple Conditions" — `elif` for chained routing.
- **016**: "Logical Operators" — `and`, `or`, `not` for complex conditions.
- **017**: "The Idea of Repetition" — Why copy-pasting code fails at scale.
- **018**: "The While Loop" — Infinite execution and state-dependent loops.
- **019**: "Breaking the Loop" — `break` and escape hatches.
- **020**: "Skipping Execution" — `continue` and filtering execution.
- **021**: "Lists (Creation)" — Grouping data in ordered sequences.
- **022**: "Lists (Access & Mutation)" — Indexing and changing elements.
- **023**: "The For Loop" — Iterating over known sequences securely.
- **024**: "Range Iteration" — `for i in range()` for controlled repetition.
- **025**: "Phase 1 Capstone" — Building a CLI Interactive Calculator.

---

## Phase 2: Builder (Missions 026–050)
**Goal**: Transition from syntax mastery to tool creation.
**Pedagogy**: Leaner stories, shift toward Mini-Projects, architecture diagrams replace basic analogies.

- **026**: "The DRY Principle" — Why code repetition is dangerous.
- **027**: "Functions (Def)" — Wrapping logic into reusable blocks.
- **028**: "Function Parameters" — Passing data into isolated contexts.
- **029**: "Function Returns" — Extracting computed results.
- **030**: "Scope" — Local vs Global memory boundaries.
- **031**: "Default & Keyword Args" — Flexible function interfaces.
- **032**: "*args & **kwargs" — Handling unknown input sizes.
- **033**: "Dictionaries (Key-Value)" — Structured data mapping.
- **034**: "Dictionary Operations" — Managing structured records.
- **035**: "Tuples" — Immutable data contracts.
- **036**: "Sets" — Uniqueness and fast lookups.
- **037**: "List Comprehensions" — Functional data transformation.
- **038**: "Dict & Set Comprehensions" — Advanced map filtering.
- **039**: "String Manipulation" — slicing, splitting, and joining text.
- **040**: "File I/O (Read)" — Persisting data beyond RAM.
- **041**: "File I/O (Write/Append)" — Modifying disk state.
- **042**: "Context Managers (`with`)" — Safe resource handling.
- **043**: "JSON Handling" — Storing structural data.
- **044**: "CSV Processing" — Tabular data basics.
- **045**: "The Fragile System" — Understanding crashes and exceptions.
- **046**: "Try / Except" — Catching and recovering from errors.
- **047**: "Else & Finally" — Guaranteed execution paths.
- **048**: "Raising Exceptions" — Defensive programming (`raise`).
- **049**: "Custom Exceptions" — Domain-specific error modeling.
- **050**: "Phase 2 Capstone" — Building a persistent CLI Task Manager with JSON.

## Phase 3: Engineer (Missions 051–075)
**Goal**: Write professional, scalable code.
**Pedagogy**: Problem-Driven. Introduce complex system limitations -> advanced concepts -> refactor.

- **051**: "The State Problem" — Why dicts and functions become messy.
- **052**: "Classes & Objects" — Encapsulating state and behavior.
- **053**: "Constructors (`__init__`)" — Initializing state securely.
- **054**: "Instance vs Class Variables" — Shared vs individual memory.
- **055**: "Methods & `self`" — Object-oriented behavior.
- **056**: "Inheritance" — Code reuse across domains.
- **057**: "Polymorphism" — Interface consistency.
- **058**: "Encapsulation" — Hiding internal state.
- **059**: "Magic Methods (Dunder)" — Overriding Python internals (`__str__`, `__eq__`).
- **060**: "Modules & `import`" — Organizing large codebases.
- **061**: "Creating Packages" — `__init__.py` and directory structures.
- **062**: "Virtual Environments" — `venv` and dependency isolation.
- **063**: "Pip & Requirements" — Third-party library management.
- **064**: "Functional: map & filter" — Declarative data processing.
- **065**: "Functional: reduce & zip" — Advanced aggregations.
- **066**: "Lambdas" — Anonymous inline functions.
- **067**: "Iterators" — The Iterator Protocol and memory efficiency.
- **068**: "Generators (`yield`)" — Lazy evaluation for massive data.
- **069**: "Decorators (Basics)" — Wrapping functions to extend behavior.
- **070**: "Decorators (Arguments)" — Advanced meta-programming.
- **071**: "Testing: The Need for Proof" — Why manual testing fails.
- **072**: "Unit Testing (`pytest`)" — Automating assertions.
- **073**: "Mocking" — Isolating tests from external systems.
- **074**: "Debugging Tools (`pdb`)" — Beyond `print` debugging.
- **075**: "Phase 3 Capstone" — OOP-based Inventory System with Pytest Suite.
