### Curriculum Dependency Rule

Every lesson, exercise, debugging task and mission challenge must introduce only ONE new core concept.

Before generating content, verify:

- Does this require knowledge from a future mission?
- Does this introduce more than one new programming concept?
- Will a beginner ask "What is that?" more than once?

If YES, redesign the lesson.

Target:

One Lesson → One Concept

One Exercise → One Reinforcement

One Debug Task → One Mistake

Never stack multiple new concepts inside a single beginner activity.
