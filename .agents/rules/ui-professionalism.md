# UI Professionalism & Settings Standards

1. **Settings & System Pages Language**:
   - The Settings page and developer control modals must be in 100% clean, professional English without secondary Bengali subtitles or bilingual parentheses.
   - Use standard developer-grade terminology (e.g., "Reading Font Size", "Code Editor", "Syntax Highlighting Theme", "Word Wrap", "Strict Evaluation Mode", "Reset All Progress").

2. **Vector Icons vs Emojis**:
   - Never use informal unicode emojis (e.g., 🌙, 🍵, ❄️, ⚡, ☀️, 💻, ⚙️, 🛡️, 🗑️) in settings, navigation controls, or theme pickers.
   - Always use clean, minimalist Lucide React SVG vector icons (e.g., `Moon`, `Coffee`, `Compass`, `Cpu`, `Sun`, `Monitor`, `RotateCcw`, `KeyRound`, `ShieldAlert`).

3. **Design System Consistency**:
   - Maintain a high-end, uncluttered aesthetic with subtle borders, muted helper text, and clear visual hierarchy inspired by Linear and Vercel.
